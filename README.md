# Otoqol — الباك اند (السيرفر)

هاد السيرفر كيخلي الداتا ديال كل مدرسة تتحفظ فالسيرفر عوض غير فالمتصفح.
كل مدرسة عندها حساب بوحدها (كود + كلمة سر)، والداتا ديالها معزولة على المدارس الأخرى.
الواجهة ديال التطبيق بقات كيف ما هي. تبدل غير الدخول: ولات **شاشة دخول وحدة** (اسم المستخدم + كلمة السر)، وزادت علامة الحفظ لتحت.

## شنو كاين
- `src/server.js` : السيرفر (Express) — الدخول (`/api/signin`)، التسجيل (`/api/signup`)، موافقة المالك (`/api/owner/*`)، نسيت كلمة السر (`/api/forgot-password`, `/api/reset-password`)، `GET/PUT /api/db`، admin API.
- `src/onboard.js` : تسجيل المدرسة ومراجعة الطلبات من المالك.
- `src/mail.js` : إيميلات استرجاع كلمة السر، وإشعار طلب جديد، ورسالة الموافقة.
- `src/db.js` : SQLite (better-sqlite3): جداول `schools` و`school_data` و`history` (نسخ تلقائية). حالة المدرسة: pending / active / rejected / inactive.
- `public/signup.html` و `public/owner.html` : صفحة التسجيل للمدارس وصفحة موافقة المالك.
- `scripts/admin.js` : أوامر الإدارة (إنشاء مدرسة، تبديل كلمة السر، توقيف، export/import، backup).
- `public/index.html` : نسخة من التطبيق، تبدل فيها غير الحفظ (sync مع السيرفر + cache فالجهاز).
- `scripts/api-test.js` و `scripts/browser-test.js` و `scripts/responsive-test.js` و `scripts/student-portal-test.js` و `scripts/dues-test.js` و `scripts/templates-test.js` و `scripts/drawer-fix-test.js` و `scripts/tasks-inbox-test.js` : تيستات.
- `Dockerfile`, `docker-compose.yml`, `ecosystem.config.js` (pm2), `render.yaml` (Render), `.env.example`.

## التشغيل (4 أوامر)
```bash
npm install
cp .env.example .env        # بدل JWT_SECRET (openssl rand -hex 32)
node scripts/admin.js create najah "مدرسة النجاح"     # كيعطيك licence + كلمة السر
node --env-file=.env src/server.js                    # http://localhost:3000
```
فالتجربة المحلية (بلا https) دير `NODE_ENV` خاوي ولا `COOKIE_SECURE=false`، حيت فـproduction الكوكي كيخدم غير على https.

## أوامر الإدارة
```bash
node scripts/admin.js create <code> "<الاسم>" [password]   # مدرسة جديدة
node scripts/admin.js list                                 # كل المدارس
node scripts/admin.js passwd <code> [كلمة_جديدة]           # تبديل كلمة السر (كيخرج كل الأجهزة)
node scripts/admin.js deactivate <code>   |  activate <code>
node scripts/admin.js export <code> file.json              # تصدير الداتا
node scripts/admin.js import <code> file.json              # استيراد (النسخة القديمة كتبقى فـhistory)
node scripts/admin.js history <code>                       # النسخ التلقائية
node scripts/admin.js restore <code> <id>                  # رجوع لنسخة
node scripts/admin.js backup [dir]                         # نسخة كاملة ديال قاعدة البيانات
```
كاين حتى admin API إلا حطيتي `ADMIN_TOKEN` (Header: `Authorization: Bearer <ADMIN_TOKEN>`):
`GET/POST /api/admin/schools`, `POST /api/admin/schools/:code/password`, `POST /api/admin/schools/:code/active {"active":false}`,
`GET /api/admin/schools/:code/export`, `PUT /api/admin/schools/:code/import {"data":{...}}`, `GET .../history`, `POST .../restore/:id`.



## وثائق NARSA (الطباعة)
- المدير أو السكريتيرة كيلقاو بوطونة «طباعة الوثائق» فلائحة «المترشحون» بجانب كل مترشح محفوظ، أو فوق فبطاقة مترشح موجود (ماشي «مترشح جديد» قبل الحفظ). من الإعدادات كيتعمّرو غير «بيانات المؤسسة (NARSA)»، ما كايناش بوطونة الطباعة تما. من بعد كيتختارو الوثيقة وكيطبعو أو كيحفظو PDF (من نافذة الطباعة: حفظ كملف PDF).
- الوثائق المتوفرة، على نموذج الجريدة الرسمية:
  1. عقد التكوين بين المرشح والمؤسسة (حتى 3 نظائر أصلية)
  2. طلب اجتياز امتحان رخصة السياقة (الملحق 1)
  3. شهادة نهاية التكوين
- الحقول كتتعمر من بيانات المترشح والمؤسسة. إلى نقصات معلومة قانونية، التطبيق كيوقف الطباعة وكيبين لائحة الحقول المطلوبة. بيانات المؤسسة كتتعمر من الإعدادات (المدير). الشهادة الطبية كيعمرها الطبيب، ما كتتملّاش أوتوماتيكيا.
- `GET /api/narsa/docs?cid=&type=contrat|demande|attestation&copies=3` (جلسة المدير أو السكريتيرة). `422 missing_fields` إلا نقصات بيانات. المونيتور كياخد 403.

## بوابة التلميذ
- المدير يقدر يفعّل أو يوقف البوابة من **الإعدادات** («تفعيل بوابة التلميذ»). افتراضياً مفعّلة.
- من بطاقة مترشح محفوظ، المدير أو السكريتيرة كيدغطو «دعوة إلى بوابة التلميذ». كيتولد رابط (صالح 7 أيام) وكيتقدر يتCopى أو يتبعث بالواتساب، وبالإيميل إلى كان عند التلميذ بريد (Brevo).
- التلميذ كيفتح الرابط فـ `/portal/invite?token=…`، كيعين كلمة السر وكيقبل معالجة بياناته (كيتسجل التاريخ وإصدار الشروط). من بعد كيدخل لـ `/portal`.
- الدخول بنفس شاشة اسم المستخدم + كلمة السر (`/api/signin` أو من `/portal`). التلميذ كيشوف غير بياناتو: الساعات، الباقي، الحصة القادمة، الجدول، طلب موعد، الأداءات، وسجل الحصص. ما كيوصلش لـ `/api/db` ولا لواجهة الموظفين.
- طلب الحجز كيحبس الموعد فحالة «في الانتظار». من «طلبات الحجز» فالمدرسة، المدير أو السكريتيرة كيقبلو أو كيرفضو. القبول كيأكد الحصة، والرفض كيحرر الموعد. سحب طلب معلّق كيكون مباشر. إلغاء حصة مؤكدة مستقبلاً كيطلب موافقة المدرسة.
- نسيت كلمة السر خدامة بحال الموظفين إلى كان الإيميل مسجّل.

## المستحقات وتذكير المدينين
- من قائمة **«المستحقات»** (المدير والسكريتيرة)، كيبانو المترشحون اللي باقي عليهم فلوس، مترتبين حسب **أيام الصمت** (من آخر دفعة أو آخر تذكير؛ الأطول أولاً).
- كل سطر كيبين: الاسم، الهاتف، الباقي، تاريخ آخر دفعة، تاريخ آخر تذكير، وعدد أيام الصمت.
- التصفية: الكل، ذُكِّروا هذا الأسبوع (من الإثنين بالمنطقة Africa/Casablanca)، لم يُذكَّروا بعد، ومستحق مرتفع (الباقي أكبر من نصف ثمن الباقة).
- الإجراءات (المدير/السكريتيرة فقط؛ المونيتور ما يقدرش): فتح واتساب برسالة تذكير جاهزة (عربية فصحى، أو فرنسية/إنجليزية حسب لغة الواجهة)، تسجيل **«تم التذكير»**، وإرسال نفس النص بالإيميل إلى كان عند التلميذ بريد (Brevo). كل تذكير كيتسجل (من، متى، القناة، والمبلغ وقتها). تاريخ التذكيرات ما كيتمسحش من الواجهة (`reminders` محمي فالسريرفر).
- نفس القائمة خدامة من تبويب **المتأخرات** فصفحة المالية.
- `GET /api/dues?filter=all|week|never|high&lang=ar|fr|en` و `POST /api/dues/:cid/remind {channel: whatsapp|email|manual, lang}`.

## قوالب الرسائل
- من **الإعدادات** (المدير فقط)، بطاقة **«قوالب الرسائل»**: لكل نوع نص بالعربية الفصحى والفرنسية والإنجليزية، قابل للتعديل، مع معاينة مباشرة واستعادة النص الافتراضي. السكريتيرة كتستعمل القوالب وما تقدرش تبدّلها.
- الأنواع: تذكير المستحقات، تذكير/تأكيد/تغيير/إلغاء الحصة، رفض الحجز، استدعاء الامتحان، ترحيب وتسجيل، دعوة بوابة التلميذ، وصل الأداء، وإشعار الغياب.
- الحقول: `{school}` `{student}` `{amount}` `{due}` `{date}` `{time}` `{instructor}` `{link}` `{phone}` (`{username}` `{paid}` `{type}` حسب النوع).
- لغة الرسالة: حقل **اللغة المفضلة للرسائل** فالمترشح، وإلا لغة المدرسة الافتراضية، وإلا العربية. واتساب والبريد كيخدمو هاد اللغة.
- القوالب محمية فالسريرفر (`messageTemplates`) وما كيتمسوش من `PUT /api/db`. التعديل عبر `GET/PUT /api/templates` و `POST /api/templates/:type/reset`.


## صندوق المهام
- من القائمة، بند **«المهام»** (فوق، جنب لوحة القيادة) فيه شارة بالعدد. كيجمع كل ما يحتاج تدخّل اليوم في مكان واحد، وكل عنصر عندو إجراء مباشر.
- تلقائيًا: طلبات الحجز والإلغاء من بوابة التلميذ (قبول/رفض)، المستحقات اللي ما تذكّرش بيها مؤخرًا (واتساب أو «تم التذكير»)، حصص الغد بدون تذكير، الحصص الماضية اللي مازال «مبرمجة» بلا حضور، الامتحانات القادمة بدون استدعاء، والوثائق الناقصة أو القريبة من الانتهاء (شهادة طبية، تأمين، زيارة تقنية، ضريبة).
- تقدر تزيد مهمة يدوية (العنوان، تاريخ الاستحقاق، مترشح اختياري، ومكلَّف)، وتعلّمها كمنجزة أو تحذفها. أي عنصر تقدر **تخفيه لليوم** ويرجع يبان من الغد.
- المونيتور كيشوف غير حصصه ومهامه ومترشحيه، وما كيشوفش المستحقات ولا وثائق السيارات ولا طلبات الحجز.
- المهام وحالة الإخفاء/التذكير محمية فالسريرفر (`tasks` و `taskState`) وما كيتمسوش من `PUT /api/db`. الواجهة بالعربية الفصحى والفرنسية والإنجليزية، ومتوافقة مع الهاتف.

## الدخول (عدة مدارس فنفس السيرفر)
- شاشة الدخول فيها: **اسم المستخدم** + **كلمة السر** فقط (بالعربية الفصحى/الفرنسية/الإنجليزية). السيرفر كيلقى المدرسة من اسم المستخدم عبر كل المدارس. مدرسة التجربة (demo) كتبقى خدامة.
- السيرفر (`POST /api/signin {username, password}`) كيتحقق من المستخدم فكل المدارس. اسم المستخدم فريد عالميًا (بلا فرق بين الحروف الكبار والصغار، والأرقام العربية ١٢٣ كتتحسب بحال 123). كيقلب فالمستخدمين (المدير/السكريتيرة) ومن بعد فالمونيتورات. إلا كان شي حساب فيه `active:false` ما كيدخلش. إلا بقاو حسابات قديمة بنفس الاسم فمدارس مختلفة، كيتختار الحساب لي كلمتو السر صحيحة؛ وإلا تفاقم التطابق، الجواب `ambiguous_login`.
- إلا كانت المدرسة `pending` الجواب 403 `school_pending` (الطلب مازال كيتراجع). إلا كانت `rejected` → `school_rejected`. إلا كانت موقوفة → `school_inactive`.
- إلا صح → كوكي httpOnly (JWT، 30 يوم) فيه المدرسة + المستخدم، والتطبيق كيدخل نيشان للصفحة ديال داك المستخدم. الصلاحيات (مدير، سكريتيرة، مونيتور) باقين كيف ما كانو.
- **أول مرة** (مدرسة جديدة ما فيها حتى داتا): دخل بـ`admin` + **كلمة السر ديال المدرسة** (لي عطيتيها فـadmin API). التطبيق كيصاوب الداتا الأولى، وكلمة السر ديال `admin` فالتطبيق كتولي هي نفس كلمة السر ديال المدرسة (ماشي 1234).
- **دخول المالك الاحتياطي**: `admin` + كلمة السر ديال المدرسة كيخدم **غير إلا ما كاينش** حساب سميتو `admin` فالتطبيق (مثلا تمسح ولا تبدلات السمية). كيدخلك بأول مدير. إلا كان `admin` موجود، خاصك كلمة السر ديالو لي فالتطبيق.
- **تسجيل الخروج**: بوطونة "تسجيل الخروج" فالفوق (كاينة فكل صفحة)، ولا من الإعدادات، ولا من "● محفوظ" لتحت → كيرجع لنفس الشاشة.
- إلا تمسح المستخدم ولا تبدلات كلمة السر ديالو فالتطبيق، الجلسة ديالو كتسالى ملي يعاود يحل التطبيق (`/api/me` كيرد 401).
- `POST /api/login {school, password}` (الدخول القديم بكلمة السر ديال المدرسة بوحدها) باقي خدام للتيستات والسكريبتات، ولكن الواجهة ما بقاتش كتستعملو. إلا شي جهاز كان داخل بيه، كيبقى داخل.


## تسجيل مدرسة جديدة وموافقة المالك
- الصفحة العامة: `/signup` (رابط من الصفحة الرئيسية ومن شاشة الدخول). المدير كيملأ: اسم المدرسة، المدينة، اسمو الكامل، الإيميل، الهاتف، اسم المستخدم، وكلمة السر. رمز المدرسة كيتولد تلقائيًا من الاسم (داخلي فقط، ما كيبانش فالواجهة).
- `POST /api/signup` كيصاوب المدرسة فحالة `pending` (ما ك تدخلش حتى الموافقة)، مع حساب المدير. اسم المستخدم خاصو يكون فريد فكل المدارس (`username_taken` إلا كان مستعمل). فيها حد للطلبات (`SIGNUP_PER_15MIN`). ما كاينش أي نص ديال الأثمنة.
- من بعد كيبان: «تم استلام طلبك وهو بانتظار الموافقة».
- كيتصاب إيميل للمالك على `contact.otoqol@gmail.com` (أو `OWNER_EMAIL`) فيه تفاصيل الطلب ورابط `/owner`. الإرسال عبر Brevo بحال الباقي.
- لوحة المالك: `/owner` — صفحة دخول بـ **اسم المستخدم + كلمة السر**، جلسة بكوكي، وحد للمحاولات. الحساب من المتغيرات: `OWNER_USERNAME` مع `OWNER_PASSWORD_HASH` (مفضّل) أو `OWNER_PASSWORD`. إلا ما كانوش هاد جوج، كتقبل `ADMIN_TOKEN` ككلمة سر (واسم المستخدم يبقى ضروري).
- داخل اللوحة كيبانو **غير حسابات المدارس**: الحالة (pending / active / rejected / inactive)، إحصائيات كل مدرسة (عدد المترشحين، الحصص، مجموع الأداءات، عدد المستخدمين، تاريخ الإنشاء، آخر نشاط)، ومجموع عام.
- الإجراءات: موافقة، رفض، إيقاف / تفعيل، إضافة مدرسة يدويًا (اسم المدرسة، اسم مستخدم المدير وكلمة السر؛ الرمز كيتولد تلقائيًا)، و**مسح** مدرسة (بعد كتابة اسمها للتأكيد). المدرسة المضافة يدويًا كتكون مفعّلة مباشرة. اسم المستخدم خاصو يكون فريد (`username_taken`). ما كيمكنش تمسح المدرسة الافتراضية (`DEFAULT_SCHOOL_CODE` / demo). المسح كيمحي المدرسة والداتا والجلسات والنسخ الاحتياطية، وكيرجّع أسماء المستخدمين متاحين.
- `DELETE /api/owner/schools/:id` (جلسة المالك) و `DELETE /api/admin/schools/:code` (ADMIN_TOKEN): الجسم `{ "name": "اسم المدرسة" }`. الأخطاء: `name_mismatch`, `protected_school`, `school_not_found`.
- الموافقة على طلب تسجيل: كتفعّل المدرسة وكاتصيفط إيميل للكليان فيه **رابط الدخول** `/app` و**اسم المستخدم** (بلا كلمة السر، حيت هو لي اختارها، وبلا رمز المدرسة).
- `PUBLIC_URL` (الافتراضي `https://otoqol.com`) كيتستعمل فالروابط داخل الإيميلات.
- إنشاء حساب المالك: رابط لمرة واحدة `/owner/setup?token=…` (صالح ساعة من تشغيل السيرفر إلا ما تستعملش). المالك كيختار اسم المستخدم وكلمة السر (8 أحرف على الأقل). كتتحفظ فالقاعدة (bcrypt) وكترجع عليها قبل متغيرات البيئة، والرمز كيتلغى من بعد الاستعمال. المتغير `OWNER_SETUP_TOKEN_HASH` (sha256 hex) هو لي كيشعل هاد الرابط فالإقلاع.

## نسيت كلمة السر (بالإيميل)
- فشاشة الدخول كاينة «نسيت كلمة السر؟». المستخدم كيكتب **اسم الدخول** فقط، والسيرفر كيلقى المدرسة أوتوماتيكيا وكيصيفط **رمز من 6 أرقام** للإيميل المسجّل فالحساب (صالِح 15 دقيقة، 5 محاولات). من بعد كيدخل الرمز وكلمة سر جديدة.
- الجواب ديال السيرفر **دائما عام** (`POST /api/forgot-password` → `{ok:true}`): ما كيبينش واش الحساب ولا الإيميل موجودين.
- الرموز كيتحفظو مشفرين (hash)، وفي حد للطلبات لكل IP ولكل حساب (`FORGOT_PER_15MIN` / `FORGOT_PER_ACCOUNT_15MIN`).
- الإيميل اختياري، والمدير كيزيدو من **الإعدادات → حسابات الفريق** (للمدير/السكريتيرة) ومن صفحة **المونيتورات**. خاص الإيميل يكون بصيغة صحيحة.
- الإرسال كيتمرّ عبر HTTPS ديال **Brevo** إلا كان `BREVO_API_KEY` مضبوط (هذا هو المسار ديال الإنتاج، حيت Railway غالبا كيحبس SMTP). إلا ما كانش المفتاح، كيبقى الإرسال بـ SMTP عبر `nodemailer` (مفيد فالاختبارات المحلية و`SMTP_HOST=capture`).
- `POST /api/forgot-password` كيرجع الرسالة العامة **دغيا** وما كيستناش الإرسال يسالي. الإرسال عندو مهلة تقريبا 10 ثواني (`MAIL_TIMEOUT_MS`).
- المتغيرات:
  - `BREVO_API_KEY` (مفتاح API ديال Brevo — تحطّو فـ Railway بنفسك، ما كيتكتبش هنا)
  - `SMTP_HOST` (الافتراضي `smtp.gmail.com`) — الاحتياطي إلا ما كانش Brevo
  - `SMTP_PORT` (الافتراضي `465`)
  - `SMTP_USER` (الافتراضي `contact.otoqol@gmail.com`)
  - `SMTP_PASS` (Gmail App Password — للاحتياطي SMTP فقط)
  - `MAIL_FROM` (الافتراضي `Otoqol <contact.otoqol@gmail.com>`؛ المرسل فـ Brevo: الاسم Otoqol والإيميل contact.otoqol@gmail.com)
  - `MAIL_TIMEOUT_MS` (الافتراضي `10000`)

## النسخ الاحتياطي على Google Drive
- فـ **الإعدادات** (المدير فقط)، بجانب تحميل واسترجاع ملف JSON، كاين خيار **Google Drive**.
- المدير كيربط حساب Google ديالو، وكيحفظ النسخة فمجلد `Otoqol Backups` فـ Drive ديالو، ويقدر يسترجع من نسخة محفوظة تما. الربط كيستعمل صلاحية `drive.file` (الملفات لي صاوبهم Otoqol فقط).
- الإرسال كيتم فالواجهة مباشرة (ما كاينش سر فالسيرفر). خاص متغير `GOOGLE_CLIENT_ID` (OAuth 2.0 Client ID من نوع Web application، والأصل المسموح `https://otoqol.com`).
- إلا ما كانش المفتاح مضبوط، السيرفر **ما كيطّحش**: كيبان فالإعدادات «ربط Google Drive غير مضبوط بعد.»، وكتبقى تحميل/استرجاع الملف خدامة.
- تحميل واسترجاع ملف JSON من الجهاز بقاو كيفما كانو.

## كيفاش خدام الحفظ
- التطبيق كيجيب الداتا من `GET /api/db`، وكل تبديل كيتسيفط بعد 1.5 ثانية `PUT /api/db` مع `version`.
- إلا جوج أجهزة بدلو فنفس الوقت → السيرفر كيرد 409، والتطبيق كيجيب الجديد ويخلط التبديلات (حسب `id` ديال كل عنصر) وعاود يسيفط. ما كيضيع حتى تبديل فالحالات العادية.
- كل جهاز كيشوف واش كاين جديد كل 20 ثانية.
- بلا انترنت: الداتا كتبقى فالجهاز (localStorage) والعلامة كتولي "بلا انترنت"، وملي يرجع الانترنت كتسيفط وحدها.
- **استيراد الداتا القديمة**: إلا كان المتصفح فيه داتا قديمة (`autoecole_db_v1`) والحساب فالسيرفر خاوي، التطبيق كيسولك واش ترفعها.

## اللغات
التطبيق كامل بالعربية والفرنسية والإنجليزية (الاختيار كيتحفظ فالجهاز). العربية RTL، والفرنسية والإنجليزية LTR. حتى رسائل واتساب والوصل كيتبعو اللغة لي مختارة.

## الحماية
- **كلمات السر**: ديال المدارس وديال المستخدمين داخل التطبيق (admin/secretary/المونيتورات) كيتحفظو bcrypt. كلمات السر القديمة لي كانت مكتوبة عاديين كيتشفرو بوحدهم فأول دخول (`admin` / `1234` كيبقى خدام). السيرفر عمرو ما كيرجع كلمة السر للمتصفح (`/api/db` كيعطيها خاوية، وخاوية = ما تبدلاتش).
- **الصلاحيات فالسيرفر**: السكريتيرة ما تقدرش تبدل المستخدمين ولا المونيتورات ولا الإعدادات، والمونيتور حتى المالية والسيارات. إلا تمسح شي مستخدم ولا تبدلات كلمة السر ديالو، كيخرج فالطلب الجاي.
- **الجلسات**: كوكي `HttpOnly` + `Secure` + `SameSite=Strict`، JWT HS256 (issuer/audience)، وكل جلسة مسجلة فالسيرفر: **تسجيل الخروج كيقتل الجلسة** (حتى إلا شي حد نسخ الكوكي).
- **Rate limit**: 240 طلب/دقيقة لكل IP، 10 محاولات دخول غالطين / 15 دقيقة لكل IP، و30 / 15 دقيقة لكل اسم مستخدم (من أي IP)، و10 محاولات غالطين ديال `ADMIN_TOKEN`. طلبات «نسيت كلمة السر»: 5 / 15 دقيقة لكل IP و3 / 15 دقيقة لكل حساب. `TRUST_PROXY=1` كيتقرا رقم (hop واحد) باش كل زبون يكون عندو الحد ديالو.
- **Headers**: CSP (بلا frames)، `X-Frame-Options: DENY`، `nosniff`، `Referrer-Policy`، `Permissions-Policy`، HSTS فـproduction. React وBabel مثبتين بنسخة محددة مع SRI.
- **CSRF**: header `X-Otoqol` ضروري فكل طلب كيبدل شي حاجة. CORS مسدود غير للـorigins لي فـ`CORS_ORIGINS`.
- **الحجم والديسك**: حد 15MB للطلب، والنسخ التلقائية (history) ما كيفوتوش `HISTORY_MAX_MB` (100MB) لكل مدرسة.
- **Docker**: كيبدا root غير باش يعطي `/data` لـuser `node`، ومن بعد التطبيق كيخدم بـ`node` (ماشي root). إلا بغيتي تخدم `scripts/admin.js` داخل الكونتينر، خدمو بـ`setpriv --reuid=node --regid=node --init-groups node scripts/admin.js ...` باش ما يتصاوبوش ملفات ديال root فـ`/data`، ولا استعمل admin API.
- ⚠️ من بعد هاد التحديث، كل الأجهزة خاصها تعاود الدخول مرة وحدة (الجلسات القديمة ما بقاتش مقبولة).

## Deploy على VPS
**pm2:**
```bash
npm ci --omit=dev && cp .env.example .env && nano .env
npm i -g pm2 && pm2 start ecosystem.config.js && pm2 save && pm2 startup
```
**Docker:** `docker compose up -d --build` (الداتا فـ`./data`). إنشاء مدرسة: `docker compose exec otoqol node scripts/admin.js create najah "مدرسة النجاح"`.

حط قدامو nginx ولا Caddy بـhttps (مثال Caddy: `otoqol.ma { reverse_proxy 127.0.0.1:3000 }`) وخلي `TRUST_PROXY=1`.

## Deploy على Render (من GitHub)
1. دخل لـ https://dashboard.render.com → **New** → **Blueprint** → ربط حساب GitHub واختار repo `otoqol`.
2. Render كيقرا `render.yaml` بوحدو. غادي يطلب منك `SEED_SCHOOL_PASSWORD`: كتب كلمة السر ديال المدرسة الأولى (6 حروف ولا كثر). من بعد **Apply**.
3. تسنى حتى يكمل الـbuild (2-5 دقايق)، وخود الرابط `https://otoqol-xxxx.onrender.com`.
4. فشاشة الدخول: اسم المستخدم `admin`، وكلمة السر لي كتبتي (أول مرة). إلا كانت المدرسة فيها داتا من قبل، `admin` بكلمة السر ديالو فالتطبيق.

**مدرسة جديدة بلا shell** (ADMIN_TOKEN كتلقاه فـRender → Environment):
```bash
curl -X POST https://YOUR-APP.onrender.com/api/admin/schools \
  -H "Authorization: Bearer ADMIN_TOKEN" -H "Content-Type: application/json" \
  -d '{"code":"najah","name":"مدرسة النجاح","password":"Najah2026!"}'
curl -H "Authorization: Bearer ADMIN_TOKEN" https://YOUR-APP.onrender.com/api/admin/schools
```
ولا بالـenv: `SEED_SCHOOL_CODE` + `SEED_SCHOOL_PASSWORD` (+ `SEED_SCHOOL_NAME`) كيخلقو مدرسة وحدة ملي كيبدا السيرفر إلا ما كانتش.

> ⚠️ **مهم:** الخطة المجانية (Free) ديال Render ما فيهاش disk دائم. يعني الداتا ديال SQLite **كتمسح** مع كل redeploy ولا restart، والسيرفر كينعس بعد 15 دقيقة بلا زيارات (أول فتحة كتاخد ~1 دقيقة). مزيانة غير للتجربة.
> باش تبقى الداتا: بدل `plan: free` لـ`plan: starter` (مخلص) وفعّل الـdisk ديال 1GB و`DATA_DIR=/var/data` فـ`render.yaml` (مكتوبين ومعلقين).

## Backups
- تلقائي: كل 10 دقايق (ملي كاين تبديل) كتتحفظ نسخة فـ`history`، و200 نسخة الأخيرة لكل مدرسة كيبقاو. وقبل كل import/restore كتتحفظ نسخة.
- نسخة كاملة كل ليلة (cron):
```
0 3 * * * cd /path/otoqol-backend && node scripts/admin.js backup >> data/backup.log 2>&1
```
كيبقاو آخر 30 ملف فـ`data/backups/`. نقلهم حتى لبلاصة أخرى (rclone / scp) باش إلا طاح السيرفر ما تضيعش الداتا.
